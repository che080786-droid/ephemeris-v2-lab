# 明月 × 晏景｜我们的家：增量 UI 改造方案

本文记录最新确认的方向，替代此前的大规模 UI 重构方案。当前仅更新文档，尚未开始施工。

## 1. 核心原则与范围

**优先保留约 70–80% 的 InternalBeyond-Mobile 原生视觉与交互，只对“明月 × 晏景｜我们的家”需要的部分做增量改造。** 此比例表达保留优先的取舍原则，不作为代码行数或组件数量的机械指标。

- 保留原 Home / Desk / Space / Circle 结构、原生视觉与交互。
- 不实施 Home / Learning / Together / Chat / Me 五项底部导航重构。
- 不大改全局 UI，不重新建立覆盖全站的设计语言。
- Space / Circle 可逐步赋予“明月 / 晏景”的身份。
- Home 未来可增加轻量“晏景 · 此刻”挂件，不重做首页。
- Together 作为新增独立入口，承载 Listen / Read / Watch Together。
- Listen Together 可以重点借鉴沉浸式歌词视觉。
- Chat 只做局部轻量美化，保留原结构。
- Memory 银河 / 生活痕迹与英语小屋后续作为新增模块接入。

此前发送的 Home、Together、Listen Together 图片及 Chat 文字描述，均降为**局部页面灵感**，不再作为重做整个应用 UI 的要求。原方案中的首页替换、全局五项导航、独立 Learning / Me 一级页面和全站主题重绘均不实施。

旧月序暂时仅计划保留 Memory 银河 / 生活痕迹的表达方式与英语小屋，其他旧模块暂不迁移。世界书暂不导入，待前端与角色体系稳定后再整理。

## 2. 原生视觉与局部参考的关系

原生字体、玻璃效果、主题、图标、导航、弹层、桌面布局和自定义外观继续作为基础。新增页面优先使用已有组件与样式能力。

| 参考方向 | 适用边界 |
|---|---|
| 共同生活感 | 新增 Together、未来“晏景 · 此刻”挂件及局部文案 |
| 大面积留白与轻层级 | Together 与共听内容区，不全局改变现有密度 |
| 英文衬线标题与中文生活文案 | 局部活动标题，沿用原生字体体系 |
| 半透明卡片与细线 | 使用原生玻璃与边框语言，不建立平行组件体系 |
| Day / Night 氛围 | 映射现有 Internal / Infernal 主题，不改主题底层 |
| 克制玫粉与浅粉白 | Chat 可选的局部配色，不覆盖全站或用户偏好 |
| 简洁底部导航 | 仅作参考观察，不实施参考图中的五项导航 |

不照搬参考中的人物、照片、日期、昵称或歌曲，不仿制系统状态栏与动态岛。文字对比、点击区域、底部安全区与减少动效优先于装饰效果。

## 3. Home / Desk：保留原生首页

保留原有 Home 与 Desk / Space / Circle 结构、桌面分页、应用矩阵、排序、挂件、抽屉和设置路径，不把原首页移到二级页面。

原生时间、月历、便笺、日程与音乐挂件继续使用。Home 参考图只用于未来局部的生活文案与陪伴表达，不按其叙事顺序重新排版首页，不新增相册模块。

### 未来“晏景 · 此刻”挂件

挂件应轻量、可选，与现有桌面尺寸、布局及外观设置兼容。具体展示内容与数据来源需在施工前确认，不默认新增后台请求或自动生成流程。

- 可以呈现简短陪伴文案或已有的真实状态。
- 固定文案与 AI 生成内容应明确区分，不冒充晏景刚刚发来的消息。
- 不使用虚构在线状态、假信件数量或未经设置的相伴天数。
- 不改变现有桌面排序与布局数据，不影响原挂件。

此挂件不是第一轮必须与 Together 同时完成的事项。

## 4. Space / Circle：逐步赋予身份

Space 可逐步成为明月的个人空间，Circle 可呈现晏景的角色身份；保留原生名片、资料展示、明暗素材与交互。

界面身份调整与实际角色配置分开处理。个人资料可能进入 AI 上下文，API 配置也关联好友、权限和历史，不能为美化而自动覆盖已有数据。

晏景人设导入另行规划；在角色未稳定前保留多角色与群聊能力，不改人物 ID，不把所有会话重绑定为晏景。

## 5. Together：新增独立入口

Together 作为现有框架内的独立入口，不替换全局导航。优先考虑接入原 Desk 的应用入口体系，具体使用 IBApps 独立 App 或已有页面扩展方式，需施工前核对接口与生命周期。

| 活动 | 表达 | 复用能力 |
|---|---|---|
| Listen Together | 一起听 | Music / 一起听 |
| Read Together | 一起读 | Coread |
| Watch Together | 一起看 | Cinema |

局部借鉴参考图的大标题、简短生活文案、克制卡片与留白，同时保持原生玻璃视觉与主题。三项活动继续使用现有数据与流程，不建立第二套播放器、阅读器或观影系统。

真实记录存在时才显示“继续上次阅读”等状态。Cinema 未启用时保留应用商店安装引导，不能假定其已可用。活动原有入口继续保留。

Letters、Calendar 与其他功能沿用原位置，不为 Together 重组整个应用。

## 6. Listen Together：局部重点改造方向

共听页面可以重点借鉴沉浸式歌词参考，优先调整呈现层：

1. 轻量关系信息与返回入口。
2. 小封面、曲名与歌手，为歌词留出空间。
3. 纵向歌词，当前句清楚突出，前后句适度淡化。
4. 细进度条与明确的当前时间、总时长。
5. 易操作的播放、暂停、切歌、歌单与原有功能入口。

保持原生播放器交互与音乐底层。无歌词时显示真实歌曲信息，不制造占位歌词；歌词滚动与字号变化避免跳动，背景不能降低阅读对比。

“一起听”沿用现有 AI 陪听能力。CONNECTED、LIVE、ROOM、BRIDGE 等状态词须对应真实能力，不暗示已有双设备同步播放。

公开网易云歌单链接 / ID 的非登录导入路线属于后续独立功能，不与本次外观改造绑定，也不修改现有登录或音乐底层。

## 7. Chat：局部轻量美化

保留原聊天结构、顶部操作、气泡系统、输入区、好友与群聊选择、频道及原生交互。Chat 参考仅影响局部视觉细节，不重新设计整个聊天页面。

| 局部区域 | 可考虑的调整 |
|---|---|
| 配色 | 可选浅粉白与低饱和玫粉，强调色小面积使用 |
| 人物信息 | 在原结构中微调头像、名字与真实状态的层级 |
| 气泡 | 保持双方区分，适度减轻视觉重量，兼容现有气泡方案 |
| 输入区 | 微调圆角、边框与间距，不移除附件、语音或原操作 |
| 陪伴细节 | 使用已有回复或播放状态，不伪造“在线” |

思考过程、工具卡、引用、附件、语音、表情包与操作菜单保持可用。用户已保存的 Visual、气泡和按好友配置不得被新默认样式覆盖。默认进入晏景会话的行为待角色体系稳定后另行确认。

## 8. Day / Night：沿用原生主题

保留现有 Internal / Infernal 的整体美化、主题切换与视觉设置。Day / Night 仅是描述局部氛围的参考，不替换主题名、全局色板或底层机制。

新增 Together、未来挂件及共听局部样式需适配两种原生主题；布局与功能一致，文字、细线及背景遮罩随主题保持可读。Chat 的可选玫粉强调也需适配暗色。

保留原有自定义背景、主题方案、明暗素材与减少动效设置，不重置用户偏好，不新增全站强制摄影背景。

## 9. 原功能复用与高级能力

Chat、Music、Memory、Blog、Coread、Cinema、Letters、Calendar，以及 API、MCP、Data、Visual、DIY、ICode、社交圈、通话与其他已有能力全部保留。复用不代表所有在线服务已完成验证。

不新增 Me 一级页面，不迁移高级功能到新的导航体系；个人资料、API、MCP、Data、设置、Guide 与应用管理沿用现有入口。

当前已有 MCP 配置、IBMCP 客户端、初始化、工具列表与工具调用，并接入现有工具分发。此次不新增 MCP 实现或外部连接。部分音乐中转配置会回退使用 MCP 中转地址，未来调整时需注意关联。

## 10. 后续新增模块与边界

### Memory 银河 / 生活痕迹

银河优先作为现有 Memory 的新增展示模块，不建立第二套记忆底层。初版可只读按时间、领域或重要程度展示星点，并进入原详情与编辑界面。

保持记忆 ID、权限、检索、衰减与 AI 注入逻辑不变。图形布局与正文分开考虑；日记、音乐及生活事件不自动全部写入长期记忆。旧银河首先借鉴表达方式，旧数据不在当前范围。

### 英语小屋

后续作为新增模块，推荐参考观影室，通过 IBApps SDK 独立接入。复用 Coread / Blog 的材料与阅读能力，按实际接口能力连接练习聊天和学习进度，不新增 Learning 一级导航。

具体存储与 SDK 能力须先核对，不假定现有接口已完整支持学习流程。不重复建立阅读数据或把学习聊天混入主线。

### 其他后续事项

晏景人设导入、世界书整理、表情包预设、公开网易云歌单链接 / ID 导入均需另行确认范围。世界书待新前端与角色体系稳定后再整理。

## 11. 第一阶段建议与验收

第一阶段建议先做 **Together 独立入口与现有三项活动的连接**，配合必要的局部生活文案；确认原生框架中的增量方式后，再开展 Listen Together 的歌词呈现优化。

| 顺序 | 建议范围 |
|---|---|
| 优先 | Together 独立入口、三项活动入口、原生主题适配与生命周期核对 |
| 后续局部 | Listen Together 沉浸式歌词呈现，保留原播放控制 |
| 独立小步骤 | Space / Circle 身份展示、轻量“晏景 · 此刻”挂件 |
| 后续确认 | Chat 局部美化、Memory 银河、英语小屋 |

不把首页重做、五项导航、全站字体色板重绘、Learning / Me 一级页面或原功能搬迁纳入施工。

实际修改文件取决于经确认的接入方式，可能涉及新增独立模块及必要的入口登记，或 index.html 的有限界面区域；不预先承诺 SDK 已具备所有跨模块能力。品牌、manifest、图标与 README 的调整如有需要，应另行明确，不为入口改造顺带全局替换。

第一阶段不删除功能、不迁移旧数据、不导入世界书、不修改数据库、聊天管道、Memory 底层或音乐底层。保留桌面布局与排序，不全局替换函数名、DOM ID、存储键或 IB 标识。上游许可与版权署名保留，明确非商业 fork 身份。

验收重点：原 Home / Desk / Space / Circle 及导航保持原有行为；新增入口可用且不挤占原入口；Listen / Read / Watch 连接正确；Cinema 安装引导有效；明暗主题与用户偏好兼容；聊天、音乐、阅读、观影及高级功能没有行为回退。

**当前状态：仅更新方案文档，暂不施工。后续实施需明确确认具体范围。**
